# Project skills

Short procedures for working on sdgen, one folder per skill with a `SKILL.md` (a `name`, a
`description` that says when to use it, then the steps). They describe how to do things and
point at repo files for the facts, so the facts live in one place.

- `run-app` — start, restart and drive the Streamlit app, screenshots included
- `test` — run the test suite and read its skips
- `diagram-conventions` — the look of the generated flow diagrams and how to check a change
- `add-reference-pack` — add a system's reference architectures or extend an existing pack
- `add-icons` — extend the diagram icon catalogue
- `onboard-template` — register a new PowerPoint template and check what the analyzer found

To add one: create `<name>/SKILL.md`, keep it under about 150 lines, imperative and specific,
without personal data or machine-specific paths.
